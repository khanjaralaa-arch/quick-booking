# 📅 Quick Booking — حجوزات سريعة

تطبيق خفيف جداً لإدارة الحجوزات والمواعيد — ملف HTML واحد، بدون خادم، بدون تثبيت.

A tiny, zero-dependency booking manager in a single HTML file. Arabic RTL UI, data stored locally in the browser.

## المميزات
- إضافة / تعديل / حذف الحجوزات (الاسم، الهاتف، الخدمة، التاريخ، الوقت، المدة، ملاحظات)
- حالات الحجز: مؤكد، بانتظار، تم، ملغي
- تنبيه عند تعارض المواعيد
- بحث وفلترة بالتاريخ والحالة + زر "اليوم"
- إحصائيات سريعة
- اتصال مباشر وزر واتساب للعميل
- تصدير واستيراد البيانات JSON (نسخ احتياطي)
- وضع ليلي تلقائي، ويعمل على الجوال

## التشغيل
افتح `index.html` في المتصفح. هذا كل شيء.

أو انشره مجاناً عبر GitHub Pages: Settings → Pages → Branch: `main`.

> البيانات محفوظة في `localStorage` على جهازك فقط — استخدم "تصدير" للنسخ الاحتياطي.
